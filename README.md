## Cómo trabajo con IA
- **Cuándo usarla:** para acelerar tareas repetitivas, aprender más rápido, prototipar y desbloquearme. **Cuándo no:** cuando no puedo verificar el resultado o necesito entender algo a fondo.
- **Cómo aplicarla:** dar contexto claro, pedir pasos pequeños, revisar siempre lo que genera y probarlo antes de darlo por bueno.
- **Criterio ante todo:** la IA multiplica lo que ya sé; por eso sigo aprendiendo los fundamentos.
